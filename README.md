**RouteSûre** est une application de bureau développée en Python permettant de consulter, d'analyser et de visualiser les données concernant les collisions routières survenues sur le territoire de Montréal. Grâce à une interface graphique intuitive, l'application facilite l'exploration des statistiques et permet de mieux comprendre l'évolution des accidents routiers au fil des années.

L'objectif de RouteSûre est de rendre les données sur les collisions routières de Montréal plus accessibles et compréhensibles grâce à des outils de visualisation interactifs. Le projet vise à simplifier l'analyse statistique et à faciliter l'identification des tendances liées aux accidents routiers.

## Installation

### 1. Cloner le dêpot

```
git clone https://github.com/ooVoo1/Accidents-routiers-montreal-Alvaro.git
```

### 2. Accéder au dossier

```
cd Accidents-routiers-montreal-Alvaro
```

### 3. Installer les dépendances

```
pip install -r requirements.txt
```

### 4. Lancer l'application

```
python src/main.py
```

## Fonctionnalités

* Gestion des fichiers CSV : Importation de fichiers CSV et chargement des données dans des DataFrames avec Pandas.

* Graphiques d'évolution annuelle : Visualisation de différentes statistiques selon les années.

* Graphiques circulaires : Représentation de la répartition des données pour une année sélectionnée.

* Graphiques à barres : Comparaison visuelle des différentes statistiques.

* Cartes thermiques : Visualisation de la distribution et de l'intensité des collisions à partir des données.

* Exportation des données : Enregistrement des données traitées au format CSV.

* Exportation des graphiques : Sauvegarde des visualisations au format PNG.

* Page d'aide : Guide intégré pour faciliter la navigation et l'utilisation de l'application.

* Interface graphique moderne : Interface développée avec CustomTkinter pour offrir une expérience utilisateur claire et intuitive.

## Utilisation

1. Ouvrir l'application RouteSûre.

2. Importer un fichier CSV contenant les données sur les collisions routières.

3. Naviguer entre les différentes sections de visualisation.

4. Sélectionner les statistiques ou les années à analyser.

5. Consulter les graphiques générés.

6. Exporter les données ou les graphiques selon les besoins.
